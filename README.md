# recipe-import-from-anything

Service that imports recipes from many sources and normalizes them to **schema.org/Recipe (JSON-LD)**.

### Inputs (planned)

* Raw text
* URL (recipe websites)
* Social networks: Facebook, Instagram, TikTok, YouTube, Pinterest
* Image
* Video
* PDF
* Notion
* HelloFresh
* (More sources over time)

### Output

* A single normalized format: **schema.org/Recipe (JSON-LD)**
